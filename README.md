# Python Mini Projects

A small collection of standalone Python scripts I've built to practice core programming logic, the kind of practical, everyday problems Python is genuinely useful for outside of data analysis work.

Each project lives in its own folder with its own code and README.

## Projects in this repo

### 🧮 [BMI Calculator](./bmi-calculator)
Takes a person's weight and height as input and calculates their BMI, then categorizes the result (underweight, normal, overweight, obese, etc.) with basic input validation.

### 🗂️ [Automatic File Sorter](./automatic-file-sorter)
Scans a folder and automatically organizes files into subfolders based on their file type (CSV, code files, images, text files, etc.), a small automation script solving a real, everyday desktop-clutter problem.

## Tools used
- Python
- Jupyter Notebook

## Why these are here

These aren't data analysis projects, they're here to show general Python fluency, working with user input, conditional logic, and file-system operations, which sit alongside the more analysis-focused SQL, Excel, and Power BI projects in my other repos.
